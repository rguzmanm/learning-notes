# Types

- In Go, you can create new types (user-defined types) by using the `type` keyword at any block level.
- These types can be `structs`, `interfaces`, derived from primitive types or derived from other user-defined types

```go
type Score int
type Converter func(string)Score
type TeamScores map[string]Score
```

- Use cases of creating new types derived from primitives include:
  - **Improved type safety:** By defining distinct types like type `UserID` int and type `ProductID int`, the compiler prevents accidental assignment of a `UserID` to a variable expecting a `ProductID`, which can prevent bugs.
  - **Adding methods:** You can attach methods to user-defined types, which is not possible with primitive types directly. A classic example is the `time.Duration` type, which is an `int64` under the hood but has methods for formatting and calculations.
  - **Semantic meaning and documentation:** A function signature like `func findUser(id int)` is less clear than `func findUser(id UserID)`

- Declaring a type based on another type is **not** inheritence.

```go
type HighScore Score
// You  can’t assign  an  instance  of  type  HighScore to  a  variable  of  type  Score, or  vice  versa.
// Any methods defined on Score aren’t defined on HighScore
```
