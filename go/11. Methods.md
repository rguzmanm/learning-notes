# Methods

- A method is a function with a special **receiver** argument, which associates the method with a specific type. There are two types of recivers:
  - **Value Receivers:** The method receives a **copy** of the receiver value. Changes made inside the method do not affect the original value.
  - **Pointer Receivers:** The method receives a **pointer** to the receiver. This allows the method to modify the original value

```go
type Counter struct {
    total       int
    lastUpdated time.Time
}

func (c *Counter) Increment() {  // Pointer receiver
    c.total++
    c.lastUpdated = time.Now()
}

func (c Counter) String() string { // Value receiver
    return fmt.Sprintf("total: %d, last updated: %v", c.total, c.lastUpdated)
}
```

- Go automatically handles the conversion between values and pointers for method calls for convenience

```go
var c Counter
fmt.Println(c.String())
c.Increment() //Automatically converted to (&c).Increment()
```

- When a type has any _pointer receiver_ methods, a common practice is to use pointer receivers for **all** methods, even the ones that don’t modify the receiver.
- You cannot define methods on built-in types directly, but you can on a type alias.

## Method sets

- A method set is the list of methods that Go considers available for that type.
  - The method set of `T` (value type) includes only methods with _value receivers_
  - The method set of `*T` (pointer type) includes methods with _value receivers_ and with _pointer receivers_
- This becomes important when dealing with _interfaces_
  - If an interface requires a method with a pointer receiver, only a pointer to the type (`*T`) can satisfy that interface.
  - If an interface requires a method with a value receiver, both the value type (`T`) and the pointer type (`*T`) can satisfy it

## Methods are functions

- In Go, you can use a method as a replacement for a function.
  - A _method value_ is a function bound to a specific instance of a type
  - A _method expression_ is a function that takes the receiver as its first argument, allowing it to be used with any value of that type

```go
type Adder struct {
    start int
}

func (a Adder) AddTo(val int) int {
    return a.start + val
}

myAdder := Adder{start: 10}

f1 := myAdder.AddTo // Method value
fmt.Println(f1(10))

f2 := Adder.AddTo  // Method expression
fmt.Println(f2(myAdder, 15))
```

## Methods on function types

- Methods can be defined on _any_ user-defined type in Go (structs, aliases of primitive types, slices, **function types**, maps, etc.)
- Some of the typical use cases for this are:
  - Satisfying an interface

  ```go
  // Define the interface
  type Handler interface {
    ServeHTTP(ResponseWriter, *Request)
  }

  // Create a function type and add the ServeHTTP method to it
  type HandlerFunc func(ResponseWriter, *Request)

  func (f HandlerFunc) ServeHTTP(w ResponseWriter, r *Request) {
    f(w, r)
  }

  func hello(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintln(w, "Hello")
  }

  http.HandleFunc("/", hello)
  ```
