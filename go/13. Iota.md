# Iota

- It is a predeclared identifier used within `const` declarations to simplify definitions of incrementing integer constants. It acts as a counter that starts at 0 and increments by one after each constant specification within a single `const`

```go
type Day int // Best practice: define a custom type for type safety

const (
    Sunday Day = iota // Sunday = 0
    Monday            // Monday = 1
    Tuesday           // Tuesday = 2
    Wednesday         // Wednesday = 3
    Thursday          // Thursday = 4
    Friday            // Friday = 5
    Saturday          // Saturday = 6
)
```

- If you insert a new identifier in the middle of your list of literals, all subsequent ones will be renumbered (which can break the application)
- iota-based enumerations make sense only when you care about being able to differentiate between a set of values and don’t particularly care what the value is behind the scenes. If the actual value matters, specify it explicitly.
