# Pointers

- A pointer is a variable that holds the location in memory where a value is stored

```go
var p *int // p is a pointer to an integer
```

- The zero value of a pointer is `null`
- The `&` is the _address_ operator.

```go
x := "hello"
pointerToX := &x
```

- The `*` is the _indirection_ operator. It retrieves the pointed-to value. This is called _dereferencing_:

```go
x := 10
pointerToX := &x
fmt.Println(pointerToX)  // prints a memory address
fmt.Println(*pointerToX) // prints 10
```

- You can't use an `&` before a primitive literal or a constant (because they don't have memory addresses)
- Go doesn't provide a mechanism to declare that other kinds of values (besides primitive literals and constants) are immutable.
- Instead, developers must use pointers to indicate that a parameter is mutable
- When a pointer is passed to a function, the functions gets a copy of the pointer. This has a couple of implications:
  - When you pass a `nil` pointer to a function, you cannot make the value non-nil

    ```go
    func failedUpdate(g *int) {
    x := 10
    g = &x
    }

    func main() {
    var f *int // f is nil
    failedUpdate(f)
    fmt.Println(f) // prints nil
    }
    ```

  - If you want the value assigned to a pointer to still be there when you exit the function, your must dereference the pointer and set the value

    ```go
    func failedUpdate(px *int) {
        x2 := 20
        px = &x2
    }

    func update(px *int) {
        *px = 20
    }

    func main() {
        x := 10
        failedUpdate(&x)
        fmt.Println(x) // prints 10
        update(&x)
        fmt.Println(x) // prints 20
    }
    ```
