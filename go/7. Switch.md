# Switch

- Cases in `switch` statements in Go don't fallthrough like in other languages
  - Therefore, if a case has no code in it, nothing will be executed.
- There is no need for a `break` keyword to end the case. However, it can be useful to:
  - Exit early within a case
  - Break a labeled loop

```go
Loop: // Label the loop
    for _, ch := range "a b\nc" {
        switch ch {
        case ' ':
            break // breaks the switch (inner statement)
        case '\n':
            break Loop // breaks the outer 'for' loop (labeled statement)
        default:
            fmt.Printf("%c\n", ch)
        }
    }
```

## Blank switches

- They are `switch` statements without a condition expression
- They are a clean way to wrtie long `if-then-else` chains

```go
t := time.Now()

	// Switch without a condition (switch true)
	switch {
	case t.Hour() < 12:
		fmt.Println("Good morning!")
	case t.Hour() < 17:
		fmt.Println("Good afternoon.")
	default:
		fmt.Println("Good evening.")
	}
```
