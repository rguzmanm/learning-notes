# Predeclared types and declarations

- `int` is a special name for an integer type. On a 32-bit CPU, `int` is a 32-bit signed integer like an `int32`. On most 64-bit CPUs, `int` is a 64-bit signed integer, just like an `int64`
- A floating-point number _cannot_ represent a decimal value exactly. Its use is not recommended to represent **money**, a third-party module should be used instead
  - In that same regard, while Go lets you use `==` and `!=` to compare floats, it's not recommended. Due to its inexact nature, two floating-point values might not be equal when you think they should be. Instead, define a max allowed variance (depending on your accuracy needs)
- `strings` in Go are immutable. Once a string is created you cannot change its contents.
  - A Go string is a **read-only byte array**
  - You can reassing strings
  - You cannot modify characters inside a string
  - Convert to `[]byte` or `[]rune` to “edit” and convert back
  - Immutability makes strings safer and more efficient, especially with concurrency

```go
s := "hello"
s[0] = 'H' // ❌ This does NOT compile
```

```go
b := []byte(s)
b[0] = 'H'

s = string(b)
fmt.Println(s) // "Hello"
```

```go
s := "hola 🌎"

r := []rune(s)
r[5] = '🌍'

s = string(r)
fmt.Println(s) // "hola 🌍"
```

- A `rune` is a built-in type that is an alias for `int32` and represents a single Unicode\* point.
  - It correctly handles multi-byte characters like Chinese characters or emojis
  - A single `rune` or `byte` can be converted to a string
  - An `int` cannot be casted directly into a `string`

```go
var a rune    = 'x'
var s string  = string(a)

var b byte    = 'y'
var s2 string = string(b)

var x int = 65
var y = string(x)
fmt.Println(y) // This will print "A" instead of "65"
```

- The `len()` function counts the number of **bytes** in a string, not necessarily the number of visibles characters
  - For ASCII characters, each character uses exactly one byte, so `len()` will match the character count
  - For Unicode chracters, a single character (or Unicode point) can require multiple bytes.
- Go doesn't allow _automatic type promotion_
- Lyterals are untyped
- Every declared variable must be read. It is a compile-time error to declare a local variable and to not read its value
  - You can (but should NOT) create unread package-level variables
  - It is possible to create unread constants with `const`

<br/>
<hr/>
<small>* Unicode is an international computing standard that assigns a unique number (code point) to every character, symbol, and emoji across all languages and platforms. It replaces legacy systems like ASCII that only supported English</small>
