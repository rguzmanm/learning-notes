# Slices

- `arrays` are a fixed-size, numbered sequence of elements of a single, specefic data type
- Its length is part of its type, meaning an array of 5 integers `[5]int` is a different type from an array of 10 integers `[10]int`

- A `slice` has three parts:
  - a **pointer** to a backing array that acts as the storage of the slice
  - a **length** that defines the number of elements in the slice
  - a **capacity** which is the maximum value the length can reach

```go
// Go runtime code for the slice type
type slice struct {
    array unsafe.Pointer
    len   int
    cap   int
}
```

- You can declare slices:
  - Using a literal: `[]T{...}`
  - Using `make` function: `make([]T, len, cap)`
  - Nil slice: `var s[T]` (len=0, cap=0, s==nil)

- A `nil slice` is different from an `empty slice` (for both `len=0`, but only `nil` compares to `nil` )

```go
// nil slice
var s []int
len(s) == 0
cap(s) == 0
s == nil   // true

// pointer = nil
// length  = 0
// capacity = 0
```

```go
// empty slice
s := []int{}
len(s) == 0
cap(s) == 0
s == nil   // false

// pointer = address of an empty array
// length  = 0
// capacity >= 0
```

- When appending elements to a slice, **capacity may be increased** (i.e., a new backing array with a bigger size is allocated)
- You can create a "slice of a slice" by using a slice expression with the syntax `slice[low:high]` from index `low` up to (but excluding) index `high`
  - This creates a new slice that provides a _view_ into the same underlying array as the original slice
- Sub-slices **share memory** with the original slice. So, modifying a subslice can modify the original slice
- Use the `copy` function to create an independent slice
- Slices aren't _comparable_.
  - It's a compile time error to use `==` to see if two slices are identical or `!=` to see if they are different.
  - Use the `slices.Equal` function to check if two slices have the same length and all of the elements are equal.
