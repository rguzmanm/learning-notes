# For loops

## For range

- Each time the `for-range` loop iterates over a compound type, it copies the value from the compound type to the value variable. Modifying the value variable will not modify the value in the compound type.

```go
// Modifying the value doesn't modify the source

evenVals := []int{2, 4, 6, 8, 10, 12}
for _, v := range evenVals {
    v *= 2
}
fmt.Println(evenVals) // Prints: [2 4 6 8 10 12]
```

- A `for-range` loop iterates over the `runes`, not the `bytes` of a `string`.
- Whenever a `for-range` loop encounters a multibyte rune in a string:
  - It converts the UTF-8 representation into a single 32-bit number and assigns it to the value.
  - The offset is incremented by the number of bytes in the rune.
- For the reasons above, it is preferable to iterate over `strings` using the `for-range` loop rather than a standard `for` loop

```go
sample := "apple_π!"
for i, r := range sample {
    fmt.Println(i, r, string(r))
}

// 0 97   a
// 1 112  p
// 2 112  p
// 3 108  l
// 4 101  e
// 5 95   _
// 6 960  π     -----> The π chracter uses more than one byte to be stored
// 8 33   !
```
